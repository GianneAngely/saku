# Security

Saku runs only on your Mac. It has no servers and no accounts, and it keeps your API keys in the macOS Keychain.

## Reporting a problem

Please don't open a public issue for a security problem. Use **Security › Report a vulnerability** on this repository instead, with the Saku version, your macOS version and the steps to reproduce it. You'll get a reply as soon as possible.

## Supported versions

Only the latest release gets fixes.
